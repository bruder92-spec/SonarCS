# Пользовательские голосовые команды Sonar
# ─────────────────────────────────────────────────────────────────────────────
# Формат строки:
#   фраза = цель
#
# Фраза  — то, что вы произносите ПОСЛЕ слова-триггера.
# Цель   — URL, путь к папке, путь к файлу или путь к программе.
#
# Примеры:
#   открой рабочую почту = https://mail.company.ru
#   открой портал        = https://intranet.company.ru
#   рабочая папка        = C:\Projects\2026
#   открой фотошоп       = C:\Program Files\Adobe\Photoshop\Photoshop.exe
#   открой инструкцию    = D:\Documents\Инструкция.pdf
#
# Правила:
#   • Строки начинающиеся с # — комментарии, игнорируются
#   • Пустые строки игнорируются
#   • Регистр фразы не важен — «Открой Почту» и «открой почту» одно и то же
#   • Длинные фразы имеют приоритет над короткими
#   • Пользовательские команды перекрывают встроенные
#   • После изменения файла перезапустите Sonar
# ─────────────────────────────────────────────────────────────────────────────
