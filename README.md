# Sonar — офлайн голосовой ввод текста для Windows

Sonar распознаёт речь прямо на вашем компьютере и вставляет текст в любое активное окно — без интернета, без облака, без видеокарты.

Специализирован для русскоязычных отраслевых задач: нефтегаз, юридическая документация, экономика и финансы.

---

## Возможности

- **Полностью офлайн** — никаких запросов в интернет, данные не покидают компьютер
- **GigaAM v3** — современная российская модель, WER ≈ 3.3% на русском языке
- **Встроенная пунктуация** — точки, запятые, заглавные буквы и цифры без постобработки
- **Отраслевые словари замен** — «э цэ эн» → ЭЦН, «эн дэ эс» → НДС и т.д.
- **Пользовательский словарь** — добавьте собственные замены в `dictionary_user.txt`
- **Очередь фраз** — начинайте диктовать следующую фразу не дожидаясь вставки предыдущей
- **Индикатор у курсора** — полупрозрачная плашка показывает состояние прямо у мыши
- **Портативный** — работает с USB-диска, не требует установки

## Быстрый старт

1. Скачать `Sonar-v1.2.zip` со страницы [Releases](../../releases/latest)
2. Распаковать в любую папку
3. Запустить `Sonar.exe`
4. При первом запуске выбрать микрофон
5. Переключиться в нужное приложение, зажать **левый Alt**, говорить, отпустить

Текст появится через 0.5–1.5 сек.

## Словари замен

После распознавания Sonar применяет отраслевые словари. Каждый включается отдельно в настройках.

| Файл | Содержание |
|---|---|
| `dictionary_oil_gas.txt` | ЭЦН, ГРП, НДПИ, КИН, МРП… |
| `dictionary_legal.txt` | ГК РФ, УК РФ, ЕГРЮЛ, ДДУ, ФНС… |
| `dictionary_economy.txt` | НДС, НДФЛ, ИНН, EBITDA, УСН… |
| `dictionary_user.txt` | **Ваши собственные замены** (создаётся вручную) |

Формат словаря — обычный текстовый файл:
```
# комментарий
произносимая форма = написание в документе
электроцентробежный насос = ЭЦН
э цэ эн = ЭЦН
```

Файл `dictionary_user.txt` достаточно положить рядом с `Sonar.exe` — он загрузится автоматически.

## Настройки

Правая кнопка на иконке трея → **Настройки**:

- **Микрофон** — выбор устройства (можно менять без перезапуска прямо из меню трея)
- **Горячая клавиша** — любая клавиша кроме Shift и Ctrl (по умолчанию: левый Alt)
- **Автозапуск** — добавляет запись в реестр `HKCU\...\Run`, без прав администратора
- **Словари замен** — вкл/выкл каждого словаря

После смены настроек приложение перезапускается автоматически.

## Диагностика

При проблемах откройте `sonar.log` рядом с `Sonar.exe`. Ключевые строки:

```
Хук установлен       — горячая клавиша работает
Модель загружена     — движок инициализирован
KeyDown              — нажатие клавиши перехвачено
Результат            — что распознал движок
```

Если антивирус предупреждает о перехвате клавиатуры (`WH_KEYBOARD_LL`) — это штатная работа программы, добавьте в исключения.

## Сборка из исходников

> Для обычного использования достаточно скачать готовый дистрибутив из [Releases](../../releases/latest) — модель уже включена.

Если вы хотите собрать Sonar из исходного кода:

```bash
# Требуется .NET 8 SDK
dotnet publish Sonar.csproj --configuration Release --runtime win-x64 --self-contained true -o dist/Sonar
```

Модель в репозитории отсутствует (215 МБ — слишком велика для git). Скачайте с HuggingFace и положите рядом с `Sonar.exe`:
- [v3_e2e_ctc.int8.onnx](https://huggingface.co/istupakov/gigaam-v3-onnx/resolve/main/v3_e2e_ctc.int8.onnx) → переименовать в `giga-am-v3.onnx`
- [v3_e2e_ctc_vocab.txt](https://huggingface.co/istupakov/gigaam-v3-onnx/resolve/main/v3_e2e_ctc_vocab.txt) → переименовать в `giga-am-v3-vocab.txt`
