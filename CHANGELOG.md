# Changelog — Sonar

## v2.2 (2026-06-25)

### Новое: пользовательские команды и автосканирование приложений

- `commands_user.txt` — пользовательские команды с наивысшим приоритетом.
  Формат: `фраза = URL / путь к файлу / путь к exe`.
  Примеры: `открой рабочую почту = https://mail.company.ru`,
  `рабочая папка = C:\Projects\2026`
- `AppDiscovery` — автоматическое сканирование Start Menu при запуске.
  Обнаруженные ярлыки доступны голосом без ручной настройки.
- Fuzzy-матчинг через транслитерацию + Левенштейн: «запусти фотошоп» →
  транслит «fotoshop» → Levenshtein ≤ 2 против «Photoshop» → совпадение.
- Порядок приоритетов: `commands_user.txt` → встроенные → Start Menu fallback.
- `CommandsForm` показывает раздел «Пользовательские команды ★» если файл существует,
  и число обнаруженных ярлыков рядом с заголовком «Приложения».
- Диагностика: `AppDiscovery` пишет в `sonar.log` количество найденных ярлыков
  и детали каждого fuzzy-совпадения (имя + score).

## v2.1 (2026-06-25)

### Исправления
- `StartsWithTrigger` теперь нормализует текст через `IntentMatcher.Normalize()` — триггер-слово срабатывает даже если GigaAM транскрибировал его со смешанными латиница/кириллица символами
- `ShowBalloonTip` полностью удалён — все ошибки (микрофон, распознавание, выполнение команды) теперь показываются через оверлей у курсора
- `SimpleRulesN` отсортирован по убыванию длины ключа — длинные правила («свернуть все окна») гарантированно матчатся раньше коротких («свернуть»)
- Версия в `AppConfig` и `Sonar.csproj` обновлена до 2.1

### Внутренние изменения
- `IntentMatcher.Normalize()` переведён в `internal` для доступа из `TrayApp`

## v2.0 (2026-06-22)

### Новое: режим голосовых команд
- Слово-триггер «компьютер» + команда → мгновенное выполнение действия Windows
- `IntentMatcher` — статический матчер на ключевых словах (~0 мс, без LLM, без сети)
- `CommandResult` — структура результата матчинга (action + args)
- `CommandExecutor` — исполняет 100+ команд: запуск приложений, управление окнами, звук, медиа, скриншоты, виртуальные столы, системные действия, клавиатурные шорткаты, набор текста
- `CommandsForm` — окно со списком всех доступных команд (открывается голосом «покажи команды»)
- `AppConfig`: поля `commands_enabled` и `trigger_word`
- `SettingsForm`: переключатель режима команд и поле триггер-слова

### Улучшения оверлея
- `OverlayForm.ShowCommandError()` — показывает «✗ Команда не найдена / «текст»» на 2 секунды
- `OverlayForm.ShowError()` — показывает ошибку распознавания через оверлей вместо BalloonTip
- `OverlayForm.ShowCommandRecording()` / `ShowCommandExecuting()` — зелёный/бирюзовый индикатор
- `_errorTimer` — автоскрытие ошибки через 2 секунды без вмешательства в нормальный поток состояний

### IntentMatcher v2.0
- `Normalize()` — заменяет визуально похожие латинские символы (a e o c x y p) на кириллические до матчинга; решает проблему смешанного скрипта GigaAM
- Предварительно нормализованные массивы `LaunchVerbsN`, `LaunchAppsN`, `FolderRulesN`, `SimpleRulesN` — нулевые накладные расходы в рантайме
- `AppNames` — канонический список приложений для `CommandsForm` (единственный источник истины)
- `TryOpenFolder` — добавлен контекст «покажи» (наряду с «открой», «открыть»)
- 30+ GigaAM-вариантов произношения приложений: Word (ворд/wort/vort/борт/молт…), Excel (эксе/аксан/eксель…), Paint (пант/пайнц/pnt…)

### Logger
- `Logger.UnknownCommand()` — нераспознанные команды пишутся в отдельный `unknown_commands.log`

## v1.0 (2026-06-10)

Первый релиз — адаптация из VoiceTyper v4.5 Final.

- Единственный движок: **GigaAM v3** (ONNX, int8, 215 МБ)
- Голосовой ввод по хоткею (левый Alt по умолчанию)
- Вставка через буфер обмена (STA-поток + Ctrl+V)
- Три отраслевых словаря замен: нефтегаз, юридический, экономика
- Оверлей у курсора: «● Запись…» / «◌ Распознавание…»
- Цветная иконка в трее (5 состояний)
- Очередь фраз — можно диктовать следующую до завершения предыдущей
- Настройки: микрофон, хоткей, автозапуск, словари
- `sonar.log` с ротацией при 1 МБ
- Портативный, не требует установки
