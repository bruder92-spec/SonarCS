Офлайн-инструмент голосового ввода текста для Windows.
Специализирован для русскоязычных отраслевых задач:
нефтегазовая отрасль, юридическая документация, экономика и финансы.
Работает полностью без интернета и без видеокарты.
Текст вставляется в любое активное окно нажатием горячей клавиши.
В режиме команд голосом управляет Windows: приложения, окна, звук,
скриншоты, виртуальные столы и многое другое.

══════════════════════════════════════════════════════════════════
  СЛОВАРИ ЗАМЕН
══════════════════════════════════════════════════════════════════

  Sonar применяет отраслевые словари замен после распознавания.
  Словарь включается / выключается в Настройках.

  Все файлы словарей находятся в папке user\ рядом с Sonar.exe.

  user\dictionary_oil_gas.txt — нефтегазовый словарь
      Заменяет проговорённые аббревиатуры на принятые в отрасли:
      «э цэ эн» → ЭЦН, «г р п» → ГРП и т.д.

  user\dictionary_legal.txt — юридический словарь
      Заменяет проговорённые термины на юридические сокращения.

  user\dictionary_economy.txt — экономика / финансы / бухгалтерия
      НДС, НДФЛ, ИНН, EBITDA, УСН и т.д.

  user\dictionary_user.txt — пользовательский словарь
      Загружается всегда, если файл существует в папке user\.
      Создайте его вручную, чтобы добавить собственные замены.
      Записи пользовательского словаря имеют наивысший приоритет.

  Формат словаря (можно редактировать в любом текстовом редакторе):
      # это комментарий
      исходный текст = замена

  Отсутствие файла словаря не является ошибкой.


══════════════════════════════════════════════════════════════════
  УСТАНОВКА
══════════════════════════════════════════════════════════════════

  1. Распаковать архив в любую папку (в т.ч. на USB-диск).

  2. Убедиться, что рядом с Sonar.exe лежат:
       giga-am-v3.onnx
       giga-am-v3-vocab.txt

  3. Запустить Sonar.exe.

  4. При первом запуске откроется диалог выбора микрофона.

  Установщик не требуется. Реестр не изменяется без разрешения
  пользователя (автозапуск — только по явному выбору в настройках).


══════════════════════════════════════════════════════════════════
  ИСПОЛЬЗОВАНИЕ
══════════════════════════════════════════════════════════════════

  1. После запуска приложение сворачивается в системный трей.
     Цвет иконки отражает состояние:

     ● Серый      — загрузка модели
     ● Синий      — готов к записи
     ● Красный    — идёт запись голосового ввода
     ● Оранжевый  — идёт распознавание
     ● Зелёный    — запись голосовой команды
     ● Бирюзовый  — выполнение команды
     ● Фиолетовый — ошибка

  2. Рядом с курсором мыши отображается полупрозрачный индикатор
     текущего состояния (● Запись… / ◌ Распознавание… и т.д.).
     При ошибке или нераспознанной команде — красная плашка на 2 сек.

  3. Переключитесь в нужное приложение (текстовый редактор,
     браузер, мессенджер и т.д.).

  4. Зажмите и удерживайте горячую клавишу (по умолчанию:
     левый Alt), произнесите фразу, отпустите клавишу.

  5. Через 0.5–1.5 сек текст появится в активном поле ввода.
     Если включён подходящий словарь — замены применятся
     автоматически.

  6. Во время распознавания можно сразу начать диктовать
     следующую фразу — она встанет в очередь и вставится
     автоматически после текущей.


══════════════════════════════════════════════════════════════════
  РЕЖИМ ГОЛОСОВЫХ КОМАНД
══════════════════════════════════════════════════════════════════

  Включается в Настройках → «Режим команд».
  Слово-триггер по умолчанию: «компьютер» (можно изменить).

  Скажите триггер + команду одной фразой:

    «компьютер, открой браузер»       — запускает браузер
    «компьютер, открой ворд»          — запускает Word
    «компьютер, свернуть все»         — Win+D
    «компьютер, закрыть окно»         — закрывает активное окно
    «компьютер, сделай громче»        — громкость +10%
    «компьютер, следующий трек»       — следующая песня
    «компьютер, скриншот»             — Print Screen
    «компьютер, скриншот области»     — Win+Shift+S
    «компьютер, заблокируй экран»     — Win+L
    «компьютер, новый рабочий стол»   — новый виртуальный стол
    «компьютер, громкость 50»         — установить громкость 50%
    «компьютер, напечатай привет мир» — вставит текст «привет мир»
    «компьютер, покажи команды»       — список всех команд

  Если команда не распознана — у курсора появится плашка
  с текстом произнесённой фразы, и она запишется в
  unknown_commands.log для анализа.

  Для запуска любого установленного приложения — просто скажите
  его название. Sonar сканирует Start Menu и находит его по
  произношению (даже если в названии только английские слова):

    «компьютер, запусти фотошоп»   — Adobe Photoshop
    «компьютер, запусти гимп»       — GIMP
    «компьютер, запусти телеграм»   — Telegram

  Пользовательские команды: отредактируйте файл user\commands_user.txt
  рядом с Sonar.exe:
      открой рабочую почту = https://mail.company.ru
      рабочая папка = C:\Projects\2026

  Полный список: скажите «компьютер, покажи команды».


══════════════════════════════════════════════════════════════════
  НАСТРОЙКИ (правая кнопка на иконке трея → Настройки)
══════════════════════════════════════════════════════════════════

  Микрофон
      Выбор устройства захвата. «По умолчанию» = системный.
      Можно менять без перезапуска прямо из меню трея.

  Горячая клавиша
      Любая клавиша кроме Shift и Ctrl.
      По умолчанию: левый Alt (VK=0xA4).

  Автозапуск
      Добавляет / убирает запись в HKCU\...\Run.
      Не требует прав администратора.

  Словари замен
      Нефтегазовый  — включает user\dictionary_oil_gas.txt
      Юридический   — включает user\dictionary_legal.txt
      Экономика     — включает user\dictionary_economy.txt

  Режим команд
      Включает распознавание голосовых команд Windows.

  Слово-триггер
      Фраза, с которой начинается команда.
      По умолчанию: «компьютер».

  После смены настроек — перезапуск приложения.

══════════════════════════════════════════════════════════════════
  ДИАГНОСТИКА
══════════════════════════════════════════════════════════════════

  При проблемах — открыть файл sonar.log рядом с exe.
  Лог пишется автоматически с момента запуска.

  Ключевые строки для диагностики:
    "Хук установлен"      — горячая клавиша работает
    "SetWindowsHookEx не удался: Win32=5"
                          — антивирус заблокировал хук,
                            добавьте в исключения
    "Модель загружена"    — движок инициализирован
    "Ошибка инициализации"— подробности в следующей строке
    "KeyDown"             — клавиша нажата и перехвачена
    "Результат"           — что распознал движок
    "Команда"             — найдена голосовая команда
    "CommandResult"       — что решил IntentMatcher
    "TextTyper: Ctrl+V"   — попытка вставки

  Нераспознанные голосовые команды:
    unknown_commands.log  — каждая строка: дата + время + текст.
                            Используйте для добавления новых
                            вариантов произношения в IntentMatcher.
